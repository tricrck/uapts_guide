# Command Centre — module guide

_Command Centre_

The Command Centre is the landing page after sign-in. Ministry and platform users see the National view; agency users see their own Agency view; and an administrator can assign a custom dashboard to an agency, department, role or person.

## Who can use it

Module **M01 · Command Centre**. Agencies with full access in the baseline policy: KENHA, KURA, KERRA, SDR, SDR_MTD, SDT, NTSA, NAMATA, KRC, KPA, KMA, NCTTCA, LAPSSET.

## Support

- **Your agency administrator** is the first contact for access, role and data-quality questions.
- **Data feeds, templates and API questions:** `api-support@uapts.go.ke` (include the `X-Request-ID` response header from a failing call).
- **Security concerns:** `security@uapts.go.ke`. Do not report suspected vulnerabilities publicly.
