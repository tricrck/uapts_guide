## Terms and acronyms

| Term | Meaning |
|---|---|
| ADS-B / AIS | Automatic position reporting for aircraft / vessels. |
| AODB | Airport Operational Database. |
| ATC | Automatic traffic counter (traffic) / Air traffic control (aviation). |
| BRT | Bus Rapid Transit. |
| IRI | International Roughness Index — road roughness; lower is smoother. |
| PCI | Pavement Condition Index. |
| KDE | Kernel density estimation, used to cluster accidents into black spots. |
| MGR / SGR | Metre Gauge Railway / Standard Gauge Railway. |
| OTP | On-time performance. |
| PSV | Public service vehicle (matatu, bus). |
| SACCO | Savings and credit cooperative operating PSVs. |
| TEU | Twenty-foot equivalent unit (container volume). |
| WIM | Weigh-in-motion — axle-load measurement on the road. |
| MFA / 2FA | Multi-factor / two-factor authentication. |
| RBAC | Role-based access control. |
| E.164 | International phone format, e.g. +254712345678. |
| Feed | A data source registered in the Integration Hub. |
| Template | A locked Excel/CSV file that defines the columns an agency uploads. |
| Commit | Writing validated upload rows into the platform's tables. |

## Support

- **Your agency administrator** is the first contact for access, role and data-quality questions.
- **Data feeds, templates and API questions:** `api-support@uapts.go.ke` (include the `X-Request-ID` response header from a failing call).
- **Security concerns:** `security@uapts.go.ke`. Do not report suspected vulnerabilities publicly.
