Data sources catalogue

Reference

Every table on a UAPTS screen is filled in one of three ways. This catalogue lists them all so you can see, for any figure, which file you would fill in or which feed supplies it.

🎬 Video tutorial: coming soon.

How to use this catalogue

  1. Find the agency that owns the data (the table is grouped by agency).
  2. Click xlsx to download the locked Excel template, or csv for the header row only.
  3. Fill in one row per record. Columns marked * are required; do not rename or reorder headers.
  4. Upload it in Integration Hub → Upload & Connect.
  5. Check the Shown on column to see which guide pages will display the data once it is committed.

There are 86 upload templates. The files are in the folder data-templates/ next to this guide.
