# Maritime — module guide

_Maritime_

Ports and shipping: vessel traffic and registry, berth and port operations, cargo and trade flows, waterways, maritime safety, green-transport indicators and port performance ranking.

## Pages in this module

| Page | What it shows |
|---|---|
| [Overview](maritime-overview.md) | headline port, vessel, inspection and safety figures at a glance |
| [Vessel Movements](vessel-movements.md) | Real-time AIS vessel traffic, port performance, KenTrade cargo single-window, and NCTTCA corridor transit KPIs |
| [Vessel Registry](vessel-registry.md) | Full vessel registry with safety certification, and the complete port-call movement log |
| [Port Operations](port-operations.md) | Berth occupancy, container throughput, KenTrade clearance data, NCTTCA corridor dwell analysis, and 60-day trends |
| [Port Services](port-services.md) | Cargo handling operations (offload / load / stevedoring), pilotage boarding-to-berthing records, and vessel / pilot / crane-equipment licensing |
| [Cargo Tracking](cargo-tracking.md) | Cargo type breakdown, import &amp; export pipeline stage tracking, cargo handling KPIs, and onward transport modes from port |
| [Imports and Exports](imports-and-exports.md) | Container throughput by loaded (export) &amp; unloaded (import) direction, yard dwell time, and the KRC/KPA port-rail container reconciliation |
| [Waterways](waterways.md) | Chartered (surveyed &amp; gazetted) and unchartered navigable waterway classification, plus navigation buoys, lighthouses, dredged channel depth, and VHF coverage |
| [Maritime Infrastructure](maritime-infrastructure.md) | Port &amp; berth registry, capacity utilisation, channel depth, navigational aids, dry docks, ICDs, and capital works |
| [Accidents & Safety](accidents-and-safety.md) | Tracked using the same framework as the UAPTS Road Safety Module: location, incident classification, severity, investigation status, and marine pollution |
| [Green Transport](green-transport.md) | KPA / KMA - Vessel fuel type &amp; emissions per TEU-km, shore power (cold ironing), EV trucks &amp; trains in the port hinterland, and cold-chain reefer energy |
| [Performance & Ranking](performance-and-ranking.md) | International-standard port KPIs and a composite ranking of Kenyan ports against each other and regional East African peers |
